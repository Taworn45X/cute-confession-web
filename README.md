# 💖 Cute Confession Web (เว็บขอเป็นแฟนสุดน่ารัก + มีมแมวต่อย & Kaneki)

เว็บสารภาพรัก / ขอเป็นแฟน แบบ Interactive Storybook แตะหน้าจอเพื่อเปลี่ยนสไลด์ สไตล์ Instagram Stories มีเสียง BGM ดนตรี Music Box คลอเบาๆ มีมแมวต่อยเมื่อกดปฏิเสธ และบทสรุปอนิเมะสุดเกรียนของ Kaneki Ken 💌

🌐 **เล่นออนไลน์ได้ที่ (Live Demo)**:  
👉 [https://taworn45x.github.io/cute-confession-web/](https://taworn45x.github.io/cute-confession-web/)

---

## 🌟 ฟีเจอร์เด่น
1. **Interactive Storybook**: แตะที่หน้าจอเพื่อเปลี่ยนสไลด์ มี Progress Bar ด้านบนสไตล์ Instagram Stories
2. **ลำดับบทพูดกวนๆ น่ารัก ไม่เลี่ยน**:
   - **สไลด์ 1**: *"นี้มันก็น่าจะนานแล้วนะ ที่รู้จักกันมา"*
   - **สไลด์ 2**: *"ขอโทษที่ใช้เวลานานขนาดนี้นะครับ"*
   - **สไลด์ 3**: *"เค้าว่ามันถึงเวลาแล้วละ..."*
   - **สไลด์ 4**: *"ขอตังเติมเกมหน่อยยยจิ ----- หยอกกก!!!"* (มีม Anya Smug + เหรียญเพชรลอย)
   - **สไลด์ 5**: ถาม *"เป็นแฟนกันไหม?"* (มีปุ่ม **"เป็นดิ รอนานละ 💖"** กับ **"ไม่เป็น 😐"**)
3. **ระบบมีมแมวต่อย (เมื่อกด 'ไม่เป็น')**:
   - จอสั่นแรง (Screen Shake) + เสียงต่อยการ์ตูน (Cartoon Punch SFX)
   - มีมแมวต่อยโผล่มาทุบหน้าจอ พร้อมแมวชี้สั่งให้ไปกดอีกปุ่ม
   - ปุ่ม "ไม่เป็น" จะค่อยๆ หดเล็กลงเรื่อยๆ และวิ่งหนีนิ้ว (Runaway Button) ขณะที่ปุ่ม "เป็น" ขยายใหญ่ขึ้นเรื่อยๆ
4. **ฉากจบสุดอลังการ (เมื่อกด 'เป็น')**:
   - ซาวด์อนิเมะสุดเบียว + เสียงระฆังฉลองชัยชนะ
   - พลุ Confetti บินกระจายเต็มจอ
   - มีม Tokyo Ghoul Kaneki Ken หัวเราะพร้อมวงเวทย์ Halo: *"ฮิๆๆๆๆ ฉันรู้อยู่แล้วละ! 😈"*
   - ป้ายชื่อคู่รัก *"เค้า ❤️ เธอ"*
   - ปุ่ม *"🔄 ย้อนดูอีกรอบ"* สวยงาม คลีนตา ไม่รก
5. **ระบบเสียง 100% Zero-Network / Offline-Safe**:
   - ใช้ Web Audio API สังเคราะห์เสียงเอฟเฟกต์ต่อย, เสียง Pop และทำนอง Music Box กล่องดนตรีสุดละมุนในตัวเครื่อง ทำงานได้ 100% บนมือถือทุกเครื่อง ไม่พึ่งเซิร์ฟเวอร์ภายนอก

## 🚀 วิธีเปิดดูในเครื่องตัวเอง (Local Preview)

```bash
cd cute-confession-web
npm start
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

---

## 🎨 วิธีปรับแต่งข้อมูล (Customization)
เปิดไฟล์ `config.js` สามารถแก้ได้ง่ายๆ:
- `senderName`: ชื่อคุณ (เช่น "เค้า", "ต้น")
- `receiverName`: ชื่อแฟน (เช่น "เธอ", "มายด์")
- `bgmUrl`: ใส่ลิงก์เพลง MP3 ของคุณเอง หรือปล่อยว่างเพื่อใช้เสียง Music Box สังเคราะห์ในตัว
- `slides`: ข้อความและรูปภาพ GIF แต่ละหน้า
